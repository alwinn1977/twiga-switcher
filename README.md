# LayoutSwitcher

Рабочий нативный прототип menu-bar приложения для macOS, которое автоматически исправляет слова, набранные в неверной русской или английской раскладке. Ввод обрабатывается только локально и не сохраняется.

## Требования

- macOS 14 или новее.
- Xcode и Xcode Command Line Tools.
- Включённые системные источники ввода US и Russian.

## Сборка и тесты

```bash
swift test
scripts/build-app.sh
open build/LayoutSwitcher.app
```

После первого запуска разрешите приложению доступ в разделах **System Settings → Privacy & Security → Accessibility** и **Input Monitoring**, затем завершите и снова откройте приложение. В строке меню появится значок клавиатуры.

## Проверка

В обычном редактируемом поле:

- `ghbdtn ` автоматически заменяется на `привет `, после чего выбирается русская раскладка;
- `руддщ ` автоматически заменяется на `hello `, после чего выбирается английская раскладка;
- `docker ` и другие распознанные корректные слова не меняются.

Проверка рассчитана на TextEdit, Notes, обычные поля Safari/Chrome и Visual Studio Code. Прототип намеренно не работает в Terminal/iTerm, SSH/удалённых рабочих столах и secure password fields. Если Accessibility API не может надёжно подтвердить безопасность поля, исправление пропускается.

## Приватность и ограничения

Приложение хранит только флаг включения автокоррекции. Текущий буфер слова живёт в памяти, агрессивно очищается и не записывается в файлы, журналы или сеть. Пользовательские словари, обучение, опечатки внутри правильной раскладки и подпись для распространения в эту версию не входят.

Для отладки разрешение Accessibility можно сбросить командой ниже. Она отзывает уже выданный доступ, поэтому после неё разрешение потребуется предоставить заново:

```bash
tccutil reset Accessibility dev.layoutswitcher.prototype
```
