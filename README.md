# Twiga Switcher

Нативное menu-bar приложение для macOS, которое автоматически исправляет слова и фразы, набранные в неверной русской или английской раскладке. Распознавание работает локально по частотным словарям в read-only `mmap`, поэтому не обращается к сети или диску на каждое нажатие.

## Требования

- macOS 14 или новее.
- Xcode и Xcode Command Line Tools.
- Включённые системные источники ввода US и Russian.

## Сборка и тесты

```bash
swift test
scripts/build-app.sh
open "build/Twiga Switcher.app"
```

После первого запуска откройте **Настройки… → Доступы**. Для «Универсального доступа» и «Мониторинга ввода» отдельно показан текущий статус и доступны кнопки **Запросить доступ** и **Открыть настройки macOS**. После выдачи доступов нажмите **Проверить снова**; macOS может потребовать перезапуск приложения. Если доступов нет, пункт **Настроить доступы…** доступен прямо в меню. В строке меню появится значок клавиатуры. Пункты **Словари…**, **Правила…** и **Настройки…** открывают нативные окна управления (их названия зависят от выбранного языка).

## Язык интерфейса

В **Настройки… → Язык интерфейса** доступны «Как в macOS», «Русский» и «Английский». По умолчанию используется основной язык macOS; если он не русский и не английский, приложение показывает английский интерфейс. Выбор сохраняется и применяется сразу ко всем окнам и меню, без перезапуска. Имена пользовательских словарей и слова в правилах остаются такими, какими их ввёл пользователь.

## Проверка

В обычном редактируемом поле:

- раскладка проверяется после каждой буквы: начиная с четырёх букв, `ghbd` заменяется на `прив`, а `рудд` — на `hell`; оставшаяся часть слова набирается уже в нужной раскладке, без ожидания пробела;
- ранняя замена выполняется только когда исходный фрагмент не является известным словом или началом слова, а в другой раскладке есть частотное словарное продолжение; короткие и неоднозначные слова проверяются на разделителе;
- пунктуацию можно набирать по клавишам нужного языка: например, `lf/` → `да.`, `lf&` → `да?`, `нуыю` → `yes.`; `!`, `)` и последующий пробел сохраняются;
- `Node.js`, `.NET`, `C++`, `machine learning`, `машинное обучение` и другие термины распознаются встроенным словарём Computer Terms;
- неоднозначное корректное слово остаётся без изменений.

Проверка рассчитана на TextEdit, Notes, обычные поля Safari/Chrome, Codex, Zoom Workplace и Visual Studio Code. В **Настройки… → Приложения** указаны режимы известных приложений; для остальных по умолчанию действует «Обычный». Здесь можно изменить режим или добавить установленное приложение. «Выключен» полностью запрещает исправления в приложении. «Обычный» исправляет только редактируемые поля, подтверждённые Accessibility API. «Совместимость» также разрешает редактируемые группы и исправления на уровне приложения, если оно не сообщает активное поле. По умолчанию Terminal/iTerm и программы удалённого доступа выключены, а Codex и Zoom работают в режиме совместимости. Поля, которые macOS явно помечает как защищённые, всегда исключены. Если приложение в режиме совместимости не сообщает тип поля, исправление может затронуть поиск или даже пароль; учитывайте это перед включением режима.

### Длинная проверка смешанного ввода

Буквальный текст из 24 строк находится в [`MixedTypingCorpus.swift`](Tests/LayoutSwitcherAppTests/MixedTypingCorpus.swift). Два теста проводят его по физическим клавишам через `KeyboardMonitor` и проверяют результат после каждой строки, а не только после отдельных слов:

```bash
swift test --filter testTwentyFourLinesWithoutManualLayoutSwitches
swift test --filter testTwentyFourLinesWithManualLayoutSwitches
# Оба сценария сразу:
swift test --filter MixedTypingIntegrationTests
```

Для ручной проверки откройте **новый пустой документ TextEdit**, включите Twiga Switcher и выберите английский источник ввода (на проверочной машине — ABC; русский — RussianWin). В первом сценарии набирайте текст из файла, не переключая раскладку вручную: физические клавиши каждого слова нажимайте так, как если бы его язык уже был выбран. Во втором сценарии начните снова в новом документе с английской раскладкой и сами выбирайте раскладку перед каждым переходом между русским и английским словом; автоматическая коррекция остаётся включённой, но не должна менять правильно набранные слова. Знаки после слова набирайте по клавишам языка этого слова, даже если приложение ещё не переключило раскладку. Позиции пунктуации проверены для ABC/US и Russian-PC (RussianWin). Не вставляйте готовый текст через буфер обмена — это не проверяет перехват нажатий.

В первом сценарии, среди прочего, должны исправляться разные последовательности с раскладочными знаками: `rjvgm.nth` → `компьютер`, `vty.` → `меню`, `k.lb` → `люди`, `,.l;tn` → `бюджет`, `k.,jq` → `любой`, `rk.x` → `ключ`, `vm.ntrc` → `мьютекс`, `gk.c` → `плюс`. Это физические последовательности при неизменной английской раскладке; при раннем переключении хвост слова сразу приходит русскими буквами. Сравните текст TextEdit с теми же 24 строками, включая пробелы, пунктуацию и заключительный перевод строки.

## Словари

Базовые английский и русский частотные словари всегда включены. Встроенный словарь компьютерных терминов включён по умолчанию и может быть отключён без перезапуска. Собственный пакет импортируется через **Словари… → Импортировать…** и представляет собой директорию с расширением `.layoutdict`:

```text
My Terms.layoutdict/
  manifest.json
  entries.tsv
  NOTICE.txt       # необязательно
```

Минимальный `manifest.json`:

```json
{
  "schemaVersion": 1,
  "identifier": "com.example.my-terms",
  "name": "My Terms",
  "version": "1.0.0",
  "description": "Project vocabulary",
  "attribution": { "source": "My team", "license": "Proprietary" }
}
```

`entries.tsv` содержит `язык<TAB>оценка 0...8000<TAB>термин`; поддерживаются `en`, `ru`, пунктуация и фразы до восьми слов:

```tsv
en	4800	Node.js
en	4600	continuous delivery
ru	4700	база данных
```

Импорт ограничен 50 МиБ, 1 000 000 записей и 4 КиБ на строку. Пакет сначала полностью проверяется и компилируется, после чего каталог заменяется атомарно. Файлы хранятся в `~/Library/Application Support/LayoutSwitcher/Dictionaries`.

## Локальное обучение

По умолчанию **Control-Shift-Z** отменяет последнее исправление в течение десяти секунд, до следующего ввода или перемещения курсора, и запрещает повторное исправление этой пары только до закрытия приложения, без записи на диск. Запрет для целого слова также блокирует раннее исправление его начала; запрет для исправленного начала блокирует повторное раннее переключение при продолжении слова. Обычный **Command-Z** остаётся командой текущего редактора. **Control-Shift-Space** принудительно исправляет текущее слово либо слово сразу после пробела и переключает раскладку для дальнейшего ввода. Исправление можно повторить для того же слова, в том числе после автоматической замены на пробеле. Оба сочетания можно изменить в **Настройки…**: выбрать модификаторы и физическую клавишу. Одинаковые сочетания для двух операций не допускаются. Прежняя пара стандартных сочетаний обновляется автоматически; пользовательские назначения сохраняются.

После принудительного исправления отдельное диалоговое окно предлагает запомнить пару: **Всегда**, **Никогда** или **Отмена**. Окно не забирает фокус у редактора, а дальнейший ввод не меняет предложенную пару. Правила можно удалить в окне **Правила…**. После успешной смены раскладки звучит системный сигнал; в **Настройки…** его можно отключить.

Поддерживаются распространённые русские Mac/PC и английские US, ABC, US International, ABC Extended, British/British PC, Canadian и Irish. Позиции букв и пунктуации берутся из выбранных системных раскладок. При отсутствии русской или английской раскладки приложение показывает отдельное уведомление и объяснение в настройках. Добавьте недостающий источник в **Настройки macOS → Клавиатура → Ввод текста → Изменить**. Проверяются включённые раскладки; после добавления источника перезапуск не требуется.

После отключения перехвата macOS приложение повторно включает его и очищает потенциально устаревший буфер. Дополнительная проверка раз в секунду восстанавливает перехват и перепроверяет временно недоступную раскладку, даже если новое системное уведомление не пришло. Перед обработкой клавиши сверяется текущий источник ввода. При ручной смене источника ввода буфер сбрасывается; собственное автоматическое переключение сохраняет исправленную часть слова. Ожидание ответа Accessibility ограничено отдельно для приложения и активного поля.

Для обычных клавиатурных событий символ сверяется с физической клавишей в текущей системной раскладке, с учётом Shift и Caps Lock. Это устраняет зависимость от устаревшего Unicode-текста события после переключения раскладки. Произвольные символы и Unicode-вставки других приложений не переинтерпретируются по физической клавише.

Приложение обрабатывает ввод локально, не ведёт журнал нажатий или диагностические счётчики ввода и не отправляет данные по сети. Текущий фрагмент текста и последнее исправление нужны только в оперативной памяти для автопереключения и отмены.

Только после явного подтверждения правила в диалоге на диске сохраняются нормализованные пары `исходное → исправленное` и действие `always`/`never` в `~/Library/Application Support/LayoutSwitcher/rules.json`. Окружающий текст, история набора и содержимое полей не сохраняются.

## Данные, воспроизводимость и скорость

Базовые данные получены из закреплённого официального wheel `wordfreq 3.1.1` с проверкой SHA-256. Данные распространяются под CC BY-SA 4.0, программный пакет wordfreq — под Apache-2.0. Computer Terms составлен специально для проекта и распространяется под CC0-1.0; исходный TSV доступен в `Dictionaries/Computer Terms.layoutdict`.

[Лицензии словарей, сведения об авторах и изменениях данных](Sources/LayoutSwitcherLexicon/Resources/Licenses/README.md) хранятся отдельно от лицензии кода и включаются в собранное приложение. Полные тексты Apache-2.0, CC BY-SA 4.0 и CC0-1.0 находятся в том же каталоге. Экспортируемый пакет Computer Terms также содержит `LICENSE.txt` и `NOTICE.txt`.

```bash
# Воспроизвести базовые индексы (создаёт изолированное Python-окружение)
scripts/generate-base-lexicons.sh

# Пересобрать встроенный предметный индекс
swift run LexiconCompiler compile-tsv \
  --input "Dictionaries/Computer Terms.layoutdict/entries.tsv" \
  --output-directory Sources/LayoutSwitcherLexicon/Resources/Lexicons/ComputerTerms \
  --manifest Sources/LayoutSwitcherLexicon/Resources/Lexicons/ComputerTerms/manifest.json \
  --source-name dev.layoutswitcher.dictionary.computer-terms \
  --source-version 1.0.0 --source-sha256 project-authored \
  --license CC0-1.0 --minimum-score 0 --subject-terms

# 10 000 прогретых mmap-поисков; бюджет 250 мс
scripts/benchmark-lexicons.sh
```

## Приватность и ограничения

Текущий буфер (не более восьми слов и 128 Unicode-скаляров) живёт только в памяти, очищается на границах безопасности и не записывается в файлы, журналы или сеть. Все словари и правила локальны. Сборочный скрипт применяет локальную ad-hoc подпись; для публичного распространения потребуется Developer ID и нотариализация.

Для отладки разрешение Accessibility можно сбросить командой ниже. Она отзывает уже выданный доступ, поэтому после неё разрешение потребуется предоставить заново:

```bash
tccutil reset Accessibility dev.twigaswitcher.prototype
```
